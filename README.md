# Golden Hour AI

Golden Hour AI is a React and TypeScript demonstration of a driving-safety monitor and emergency-response workflow. The interface uses simulated data and does not contact emergency services.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The application source is in `src/`. Figma Make configuration and helper scripts remain in `figma/make/`.
